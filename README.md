# AgroSphere API Gateway

Milestone 1C, release 0.2.0. Independent Java 25 / Spring Boot 4.0.9 / Spring Cloud 2025.1.4 (Gateway MVC 5.0.4). The existing compatible MVC starter is retained. No domain logic, database or discovery server is added.

Run ./mvnw verify (Windows: .\mvnw.cmd verify) on JDK 25. Twelve JUnit 5 tests manage contexts explicitly: the original four security checks and eight real HTTP/RSA-JWKS integration cases cover routes/query strings/bearer propagation, POST/Location, correlation, signature/issuer/audience/expiry, CORS, rate limits and downstream timeouts. SpringExtension is intentionally unused under the existing Spring 7/JUnit 5 baseline. Build independently with docker build -t agrosphere-api-gateway:0.2.0 .; the pinned Maven/Temurin25 builder runs verification, and runtime UID/GID is 10001:10001.

Routes preserve paths: /api/v1/estates/**, /divisions/**, /blocks/** and /rubber-clones/** under /api/v1 go to ESTATE_SERVICE_URL (http://localhost:8081); /api/v1/spatial/** goes to SPATIAL_SERVICE_URL (http://localhost:8082). Nested estate/division/block paths use the existing Estate API semantics. No rewrite or duplicate route mappings are introduced. Only Actuator health/probes are public. JWTs require RS256 signature, exact issuer, lifetime and OIDC_AUDIENCE (agrosphere-api). Services independently enforce their audience, roles and estate scope.

Required: OIDC_ISSUER_URI. Optional: OIDC_JWK_SET_URI for a container-reachable trusted JWKS URL without changing the public issuer; absent uses issuer discovery. SERVER_PORT defaults 8080. CORS_ALLOWED_ORIGINS defaults http://localhost:4200, comma-separated exact origins; Authorization/Content-Type/correlation/trace headers are allowed. Browser clients use bearer tokens; the gateway is stateless and disables CSRF. CORS preflight is processed before authentication.

GATEWAY_CONNECT_TIMEOUT=2s and GATEWAY_READ_TIMEOUT=10s explicitly configure the JDK request factory used by the observed Gateway RestClient; redirects are not followed. Connection/read failures return safe 503 Problem Details with correlationId; downstream HTTP statuses/bodies and Location remain intact. There are no automatic command retries. Missing/invalid X-Correlation-ID becomes a UUID; valid IDs reach downstream and response. Structured JSON access logs include method, path (without query), status, duration and correlationId; tokens/bodies are omitted.

GATEWAY_RATE_LIMIT defaults 120 API requests per authenticated subject per fixed minute. The bounded in-memory map holds at most 10,000 subjects and clears each minute. Exhaustion returns 429 and Retry-After. Limits are per process and reset on restart, suitable for this single local gateway; distributed enforcement requires a separately reviewed store. Health checks bypass the limiter.

For the integrated platform use agrosphere-infrastructure --profile apps; all centralized development configuration and Keycloak PKCE provisioning are documented there. Standalone Spring does not automatically load .env. Export variables from .env.example before ./mvnw spring-boot:run. Set MANAGEMENT_OPENTELEMETRY_TRACING_EXPORT_OTLP_ENDPOINT to an OTLP HTTP /v1/traces endpoint to export; TRACING_SAMPLE_PROBABILITY defaults 0.1. Readiness reports gateway availability; downstream availability is handled per request. The infrastructure acceptance suite additionally verifies actual Keycloak, Estate/Spatial and Jaeger integration.

POST/PUT/PATCH JSON bodies are limited to 2 MiB by gateway.limits.body-bytes; declared-length and streaming bodies are both bounded before proxying. Excess returns 413 Problem Details. The integration test includes both transfer styles. The shared platform also authenticates real development users through PKCE and independently tests backend authorization.

Milestone 3B forwarding regression: 13 tests include collection Idempotency-Key, bearer, correlation and exact JSON body preservation plus /collections/summary date/group queries through the existing /api/v1/tapping/** route. Browser CORS preflight explicitly permits Idempotency-Key. No collection business logic is added to Gateway.
